# Buch Trader V1

## Notes

* To debug server, open server in its own vscode window, go to run and debug, and run (or run `node --inspect src/server.js`)
* Make sure private key h

## Commands

* `npm start`: Starts client
* `nodemon run dev` or `npm start`: Starts server (nodemon for dev)
* `tree -I node_modules`: Prints tree without node_modules
